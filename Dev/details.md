# Menu Items

- **Compile**: Compiles C# WPF file into `.exe` (.cs files)
- **Import**: Imports .nss files to iMA Menu (.nss files)
- **Pip**: Installs all pip requierments in current path (.py path/files) **CTRL + Right Click**
- **Terminal**: Opens Command Prompt in directory (anywhere) **CTRL + Right Click**
- **Run py**: Executes Python script in terminal (.py files) **CTRL + Right Click**
- **Build (Python)**: Packages script with PyInstaller (.py files) **CTRL + Right Click**
- **npm install**: Installs dependencies, builds project, triggers Firebase init (package.json) **CTRL + Right Click**
- **Dev**: Starts development server via `npm run dev` (package.json) **CTRL + Right Click**
- **Build (Node)**: Builds project assets via `npm run build` (package.json) **CTRL + Right Click**
- **Deploy**: Deploys project to Firebase hosting (package.json) **CTRL + Right Click**
- **Antigravity**: Launches target in Antigravity IDE (any file/folder) **CTRL + Right Click**
